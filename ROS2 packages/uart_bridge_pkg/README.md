# Uart Bridge Package (`uart_bridge_pkg`)

ROS 2 пакет для мостового соединения (UART Bridge) между одноплатным компьютером Orange Pi 3b и микроконтроллером STM32. 

Нода `uart_bridge_node` транслирует команды управления движением (`/cmd_vel`) в бинарные пакеты для STM32, а также читает данные 6 энкодеров по UART, рассчитывает одометрию с помощью прямой кинематики (skid-steering) и публикует ее в топик `/odom`. Кроме того, нода поддерживает динамическое изменение параметров ПИД-регуляторов моторов "на лету" (например, через `rqt`).

## Особенности
* **Прямая трансляция управления:** Конвертирует `geometry_msgs/msg/Twist` в компактные бинарные UART-пакеты с расчетом контрольной суммы (CRC-8).
* **Расчет одометрии (Skid-Steering):** Опрашивает энкодеры в отдельном потоке, переводит тики в метры и вычисляет координаты X, Y, Theta на основе ширины колеи (290 мм) и геометрии 6 колес.
* **Настройка ПИД "на лету":** Обработчик параметров ROS 2 позволяет отправлять пакеты настройки на микроконтроллер без перезапуска ноды.
* **Веб-дашборд (`web_dashboard_node`):** Встроенный Flask + SocketIO сервер для отображения графиков энкодеров в реальном времени и настройки ПИД-коэффициентов через веб-интерфейс в локальной сети.

## Топики

### Подписки (Subscribers)
* **`/cmd_vel`** (`geometry_msgs/msg/Twist`): Целевая скорость робота. 
  * Используются поля `linear.x` (линейная скорость) и `angular.z` (угловая скорость).

### Публикации (Publishers)
* **`/odom`** (`nav_msgs/msg/Odometry`): Локальная одометрия робота (X, Y, Theta). 
  * Публикуется с фреймами `odom` -> `base_link` (публикация TF-трансформации отключена).
* **`/encoders_raw`** (`std_msgs/msg/Int32MultiArray`): Сырые значения энкодеров (разница тиков с прошлого пакета) для всех 6 колес. Используется для отладки.

## Параметры ROS 2 (Parameters)

| Имя параметра | Тип | По умолчанию | Описание |
|---|---|---|---|
| `serial_port` | string | `/dev/ttyS7` | Имя устройства UART-порта на Orange Pi 3b |
| `baudrate` | integer | `115200` | Скорость передачи данных UART |
| `motor_id` | integer | `0` | ID мотора (0-5) для отправки новых ПИД-коэффициентов |
| `kp` | double | `1.0` | Пропорциональный коэффициент (P) для `motor_id` |
| `ki` | double | `0.0` | Интегральный коэффициент (I) для `motor_id` |
| `kd` | double | `0.0` | Дифференциальный коэффициент (D) для `motor_id` |

*Примечание: При изменении параметров `kp`, `ki`, `kd` или `motor_id` (например, через `rqt` или `ros2 param set`), нода автоматически формирует пакет и отправляет его по UART в STM32.*

## Установка и сборка

1. Перенесите папку `uart_bridge_pkg` в директорию `src` вашего ROS 2 workspace на Orange Pi 3b.
   ```bash
   cd ~/ros2_ws/src
   # Убедитесь, что папка uart_bridge_pkg находится здесь
   ```

2. Соберите пакет с помощью `colcon`:
   ```bash
   cd ~/ros2_ws
   colcon build --packages-select uart_bridge_pkg
   ```

3. Подгрузите окружение workspace:
   ```bash
   source install/setup.bash
   ```

## Запуск

### Базовый запуск
```bash
ros2 run uart_bridge_pkg uart_bridge_node
```

### Запуск с переопределением порта
Если вам нужно изменить UART порт без правки кода:
```bash
ros2 run uart_bridge_pkg uart_bridge_node --ros-args -p serial_port:=/dev/ttyS0 -p baudrate:=115200
```

### Запуск веб-дашборда
Для запуска графического интерфейса откройте отдельный терминал и выполните:
```bash
ros2 run uart_bridge_pkg web_dashboard_node
```
Затем откройте браузер на любом устройстве в вашей локальной сети по адресу:
`http://<IP_адрес_Orange_Pi>:5000`

## Права доступа к UART
Убедитесь, что ваш пользователь на Orange Pi находится в группе `dialout` (или `tty`), чтобы иметь права на чтение/запись в `/dev/ttyS7` без `sudo`:
```bash
sudo usermod -a -G dialout $USER
# После этого нужно перезайти в систему или выполнить su - $USER
```
